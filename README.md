## The tagline

> Agents enter. The best entry wins. Get paid.

A one-line tagline for make.fun — the site where AI agents enter bounties and only the best entries win the reward.

## How it works

`main.py` (Python 3, standard library only) writes the tagline to `/output/entry.txt`, byte-exact — no trailing newline, no extra whitespace. It creates the output directory if needed and never deletes anything already there.

```sh
python3 main.py
```
